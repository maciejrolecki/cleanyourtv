# Proximus V7 Decoder (Technicolor UIW4020PXM, codename uiw4020pxm, Broadcom BCM7271, 2 GB RAM), Android TV 12,
# firmware PXM-SW-12.0.5 (build STT5.251221.001, security patch 2026-07-01), Belgium
# Operator IPTV box used WITHOUT a Proximus TV subscription, on Ethernet. Lived with for about two weeks,
# with many reboots. Some packages below were disabled by hand before this list was written, the rest over ADB.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/proximus-v7-uiw4020pxm/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/proximus-v7-uiw4020pxm/debloat.txt be.px.stbtvclient
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: be.px.stbtvclient (the Proximus TV app) declares HOME. With it disabled, the only other
# HOME is com.android.tv.settings/.system.FallbackHome (priority -1000), so a third-party launcher takes Home.
# A Proximus TV subscriber must keep the whole "Proximus TV service" group below.
#
# Language: Settings offers only English, Nederlands and Français. The firmware (framework-res, TvSettings)
# ships only en/fr/nl resources. Other locales (e.g. pl-PL) can be set through
# ActivityManager.updatePersistentConfiguration run as the shell user (app_process). Apps and the launcher
# follow, while the system menus stay in English.
#
# PERSISTENT: com.technicolor.ota, .android.remotecontrolservice, .android.dtvinput, .android.cas.provider,
# .android.user.provider and .onetouchplay are pkgFlags PERSISTENT. Android starts them at every boot even
# when disabled, so disabling them frees nothing. They are listed commented out below.
#
# Netflix (com.netflix.ninja) starts at boot and is on the system deviceidle whitelist. com.technicolor.dm
# sends it its ESN at boot, and com.broadcom.nrdphelper monitors it. RUN_ANY_IN_BACKGROUND=ignore and
# force-stop do not keep it from starting. Its BootCompleteReceiver cannot be disabled from the shell
# (SecurityException). Leave nrdphelper and technicolor.dm alone, since Netflix certification depends on them.
#
# Kept: Play Store and Play Services, Gboard, Bluetooth, System UI, TV Settings, Chromecast
# (com.google.android.apps.mediashell), Dolby audio, all com.broadcom.* services, com.technicolor.dm,
# hddtemperaturemonitor, pxmledcontroller, hardwareproperties, and the updaters (see the end of this list).
